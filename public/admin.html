ACCÈS ORGANISATEUR · R2 PRIVÉ

Les archives du Père Noël

Cet espace importe des albums bilingues dans le stockage Cloudflare R2 privé. Les fichiers restent hors de GitHub et ne sont révélés qu'aux dates autorisées.

01

Autorisation

Le site est protégé par Cloudflare Access. Saisis le jeton administrateur créé dans Cloudflare pour importer les albums.

02

Calendrier bilingue

Sélectionne le fichier JSON privé des 24 cases (titres, descriptions et légendes FR/EN). Il n'est pas envoyé dans GitHub.

03

Photos et vidéos

Sélectionne le ZIP initial ou plusieurs fichiers médias. Les noms sont associés automatiquement aux entrées du calendrier. Les fichiers sont transmis directement à R2, un par un, sans passer par GitHub.

N'utilise pas une URL publique R2. Conserve le bucket privé et règle un jeton administrateur long et aléatoire.
